## 🚀 ЧТО ЭТО

SpotHub Android — патчер для Spotify на Android. Он забирает установленный Spotify с вашего телефона, удаляет рекламу, включает премиум-функции и ставит обратно.

Никаких готовых APK. Всё делается на вашем телефоне.

## 🔧 УСТАНОВКА

### 1. Установите ADB

Скачайте Platform Tools от Google: https://developer.android.com/studio/releases/platform-tools

Распакуйте в удобное место и добавьте в PATH.

### 2. Включите отладку на телефоне

- Зайдите в Настройки → О телефоне
- Нажмите 7 раз на Номер сборки
- Вернитесь → Для разработчиков → Отладка по USB → ВКЛ

### 3. Скачайте SpotHub

Откройте командную строку и выполните:

git clone https://github.com/m31226953-wq/SpotHub_Android_ADB.git
cd SpotHub_Android_ADB

### 4. Запустите патчер

Подключите телефон к компьютеру и запустите:

adb_patch.bat

Скрипт сам:
- Вытащит Spotify с телефона
- Наложит патчи
- Соберёт и подпишет APK
- Установит обратно

## ❓ ЧАСТЫЕ ВОПРОСЫ

Вопрос: Нужен ли рут?
Ответ: Нет. Всё работает без рута.

Вопрос: Spotify обновился, патчи слетели?
Ответ: Запустите скрипт ещё раз — он снова заплатит.

Вопрос: Сколько времени занимает?
Ответ: 2-3 минуты.

Вопрос: Банят за это?
Ответ: Spotify не банит за клиентские патчи.
